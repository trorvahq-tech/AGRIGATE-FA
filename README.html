📱 Core Features

What the Application Can Do

A comprehensive suite of tools designed for field agents to manage their entire farming operation workflow — from farmer registration to harvest logging and beyond.

👨‍🌾

Farmer Onboarding & Registration

Multi-step registration wizard capturing farmer biometrics, demographics, NIN verification, household data, and livelihood indicators. Supports GPS-tagged farm boundary mapping with vertex plotting.

🗺️

Farm & Field Management

Create, view and manage farms with subplots. GeoJSON boundary mapping, centroid tracking, soil type analysis, and cropping system assignment. Each field links to activities, assessments and harvest logs.

📋

Task Management & Scheduling

Complete task lifecycle — create, assign, track, and close tasks. Overdue detection, due date filtering (today/tomorrow/overdue), and category-based grouping (fertilization, pest control, monitoring, etc.).

📊

Season Tracker & Cropping Calendar

Visual timeline showing planting season progress by state. Automatically merges cropping system templates with real-time activity data. Displays week-by-week Gantt-style activity calendars.

📞

Auto Call Sequencer

Sequential dialer that queues and auto-dials farmers one by one. 5-second countdown before each call, outcome logging (Connected / Busy / No Answer), and call notes for verification details.

🧭

Route Optimizer & Navigation

Interactive SVG map displaying farmer locations with optimized visit routes. Deep-links to Google Maps for turn-by-turn navigation from agent's current GPS position to each farmer stop.

👥

MTG Groups & Meetings

Create and manage Mutual Trust Groups. Add/remove farmers, schedule meetings with SMS notifications via Termii, track attendance, and manage group training sessions and funding rounds.

💰

MTG Funding & VSLA

Village Savings & Loan Association tracking — record member contributions, input finance rounds, calculate balances, and generate review summaries for cooperative savings programs.

📝

Activity Logging & Validation

Log farming activities with geo-tagged photos, GPS timestamps, and agent notes. Activities flow through validation pipelines — awaiting validation, validated, or rejected.

🌾

Farm Assessment & Scoring

Structured assessment forms with VCM Scorecard integration. Evaluate farm health, compliance, regenerative practices adoption, and generate actionable recommendations.

📲

SMS Notifications (Termii)

Bulk SMS broadcasting to farmers via Termii API. Personalized templates with dynamic fields ({name}, {group}, {time}, {location}). Used for meeting reminders, task alerts, and announcements.

🌍

Multi-Language Support

Internationalization (i18n) with translations for Hausa, Yoruba, Igbo, and English. Agents can switch languages dynamically. All UI labels, alerts, and system messages are translatable.

🎯 Strategic Framework

How It Supports VCM & SCL Decision-Making

The platform is purpose-built to support two critical frameworks in smallholder agriculture development: Value Chain Management and Sustainable Community Livelihoods.

🔗 Value Chain Management (VCM)

End-to-end visibility from input sourcing through production, processing, and market access.

  • ✓ Input Tracking: Records fertilizer, seed, and agrochemical usage per farm and subplot. Tracks input finance credits and repayment status.
  • ✓ Production Monitoring: Cropping calendar aligns activities to expected timelines. Season tracker flags deviations. Activity logs capture real-time field operations.
  • ✓ Quality Assurance: VCM Scorecards rate farm compliance. Assessment forms evaluate soil health, GAP (Good Agricultural Practices), and regenerative farming adoption.
  • ✓ Harvest & Yield: Harvest logs record yield data, enabling yield-per-hectare analysis. Farm reports compare performance across agents, regions, and seasons.
  • ✓ Agent Performance: Dashboard KPIs track farm visits completed, activities logged, assessments done, and harvest logs recorded — measuring agent effectiveness in the value chain.

🏘️ Sustainable Community Livelihoods (SCL)

Community-level interventions that improve food security, financial inclusion, and resilience.

  • ✓ Food Security Data: Farmer registration captures meal frequency, food shortage months, and water sources — directly informing SCL food security assessments.
  • ✓ VSLA & Financial Inclusion: MTG funding modules track village savings, loan disbursements, and contribution cycles — key SCL indicators for financial empowerment.
  • ✓ Household Profiling: Captures household size, dependants, schooling children, education level, and livelihood diversity (livestock, poultry, aquaculture) for vulnerability scoring.
  • ✓ Community Safety: Security threat levels and conflict exposure data collected during registration inform community resilience planning and intervention targeting.
  • ✓ Group Strengthening: MTG management, training sessions, and meeting attendance tracking build social capital. SMS notifications ensure community engagement and participation.
🧠 Decision Intelligence

Data-Driven Decision Support

Every data point collected flows into actionable insights for agents, project managers, and program directors.

Field Agent

Prioritize Daily Visits

The "Needs Visit" queue with route optimization tells agents exactly which farms to visit, in what order, and provides Google Maps navigation — eliminating guesswork.

Field Agent

Auto-Call Sequencing

The sequential auto-dialer reduces call-making friction. Outcome logging (connected/busy/no answer) creates call analytics that reveal farmer reachability patterns.

Project Manager

Season Progress Monitoring

The cropping calendar + season tracker provides real-time visibility into which farming stages are on schedule, delayed, or skipped — enabling proactive intervention.

Project Manager

Input Finance Risk Assessment

MTG contribution data + farm assessment scores help identify which farmers are high-risk for input credit defaults vs. which are likely to repay — informing lending decisions.

Program Director

Vulnerability Targeting

Household profiling data (food shortage months, water sources, security threats) surfaces which communities need the most support — aligning SCL interventions with actual need.

Program Director

Impact Measurement

Yield data, farm visit frequency, activity completion rates, and VSLA savings growth — all tracked over time — provide the metrics needed for donor reporting and program evaluation.

⚙️ Technical Architecture

System Architecture & Stack

Built on modern, production-grade technologies with offline-first capabilities for rural connectivity challenges.

Mobile App

React Native + Expo

Cross-platform iOS/Android app built with Expo Router (file-based routing), React Query for server state, AsyncStorage for offline caching, and NativeWind for styling.

Backend API

Node.js + Express + PostgreSQL

RESTful API with JWT authentication, role-based access control, Drizzle ORM, and structured feature-based architecture. Deployed on Render with managed PostgreSQL.

Notifications

Termii SMS Gateway

Integrated Termii API for bulk SMS delivery to Nigerian phone numbers. Automatic 0→234 normalization. Personalized message templates with dynamic field substitution.

Admin Panel

Next.js Web Dashboard

Administrative web interface for project managers. Manage projects, view farmer registrations, review reports, and configure cropping system templates.

Authentication

JWT + Demo Mode

Dual-mode auth: production JWT tokens with refresh rotation, plus a fully-functional offline demo mode for training and presentation purposes.

Maps & GPS

Google Maps + GeoJSON

GPS coordinate capture for farm boundaries, centroid calculation, GeoJSON polygon storage, and Google Maps deep-linking for agent field navigation.
